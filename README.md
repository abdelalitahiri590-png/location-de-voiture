# 🚗 Moroccan Car Rental Management System

A full-stack web application designed for managing car rental operations, reservations, and fleet availability in Morocco.

## 🛠️ Tech Stack & Technologies
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** PHP
* **Database:** MySQL / MariaDB (`car_rental.sql`)

## ✨ Key Features
* **Fleet Management:** Browse available cars with specifications and daily rates.
* **Booking System:** Seamless car reservation interface for users.
* **Admin Dashboard:** Control panel to manage vehicles, customers, and bookings (`dashboard.php`).
* **Database Integration:** Structured SQL database setup included.
